# Valentín Lineiro

**Staff Software Engineer · Systems thinker · Independent builder**

I build software systems and explore how to make engineering more reliable, decisions more rigorous, and automation more useful.

My work sits at the intersection of **software architecture, AI-assisted engineering, and lightweight governance**. I care about evidence over assumption, useful constraints over process for its own sake, and tools that reduce friction without hiding complexity.

## Selected work

| Project | Focus |
| --- | --- |
| [**TAKT**](https://github.com/valentinlineiro/takt-theory) | Formal methods for decision-preserving systems, with Lean proofs and a verifiable runtime reference. |
| [**Provena**](https://github.com/valentinlineiro/provena) | Professional identity and job-market observation designed to make decisions traceable and preserve attention. |
| [**Meridian**](https://github.com/valentinlineiro/meridian) | Longitudinal analytics built around historical evidence, change detection, and auditable findings. |
| [**Cádiz: Walk or Bus**](https://github.com/valentinlineiro/cadiz-walk-or-bus) | A real-world PWA that compares walking time with live public-transport arrivals and communicates uncertainty honestly. |

## What I explore

- **Architecture:** systems that remain understandable as they evolve.
- **AI-assisted engineering:** automation with explicit boundaries, checks, and feedback loops.
- **Decision quality:** knowing what evidence is sufficient to act.
- **Product engineering:** turning ideas into useful, reliable software.
